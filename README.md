# 🌐 My Portfolio Website

Welcome to my portfolio project! This website was built as part of an educational workshop at **Lexicon**.

🚀 **View the live website here:** [https://baraajam.github.io/portfolio-page/](https://baraajam.github.io/portfolio-page/)

---

## ✨ Features

* **Sticky Glass Navbar:** A modern navigation bar that sticks to the top of the screen and fades in a blurry background effect (`backdrop-filter`) when scrolling.
* **Smooth Scrolling:** Clean and seamless navigation transitions that slide smoothly to sections when menu items are clicked.
* **Responsive Design:** The entire layout adapts cleanly to look beautiful on desktop monitors, tablets, and mobile screens.
* **Dark Theme Toggle:** A theme switch button in the navigation bar that toggles between light and dark modes using smooth CSS transitions.

---

## 🛠️ Technologies & Tools

This project was built from scratch with a focus on clean, semantic web development practices:

* **HTML5:** Semantic architecture (`<nav>`, `<header>`, `<main>`, `<footer>`) used for accessibility and structure.
* **CSS3:** Built using Flexbox grid layouts, custom CSS properties/variables (`:root`) and state transitions.
* **JavaScript (ES6):** Used event listeners (`addEventListener`) to power the dynamic scroll styles and the dark mode theme switch mechanism.
* **Git & GitHub:** Version control management and automated deployment pipelines via *GitHub Pages*.

## 🧑‍💻 How to Run the Project Locally

If you want to download and review the code on your own machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/BaraaJam/portfolio-page
   ```
2. Open the project folder in your code editor (such as VS Code):
   ```bash
   cd portfolio-page
   code .
   ```
   
3. Launch the `index.html` file (using the *Live Server* extension in VS Code is highly recommended).
